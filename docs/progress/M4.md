## Real public compatibility

Two independent licensed Figshare sources were fully compared with ReadStat1.3.3 and GNU PSPP2.0.1: 634x88 (55792 cells) and 87x111 (9657 cells). The ReadStat/raw-dictionary comparison includes names, order, type, width, labels, missing definitions/atoms, raw print/write formats, display metadata, weight reference and retained extension payloads. PSPP separately verifies all values/numeric missing predicates and a generated roundtrip. Both public results have zero unexplained differences.

Normalizations are explicit: ReadStat trims fixed-width string spaces and one source label trailing ASCII space; MoonSav retains the original bytes. System missing maps to None only in oracle comparison. Source hashes, authors, license and source URLs are in AC03 reports/fixtures manifest. Raw public data and generated bundles remain ignored cache/payloads; evidence contains aggregate comparisons, not individual rows. No compatibility percentage or claim covering all SAV files is made.

Four targeted codec positive fixtures passed ReadStat and PSPP. The extra GB18030 U+10000 four-byte fixture passed MoonSav, GNU PSPP/libiconv, independent Python codec and primary range mapping; the Mac ReadStat wheel/system iconv rejects this valid input. Its exact failure and SHA are retained, classified oracle_unsupported, not silently skipped or called a ReadStat pass.
