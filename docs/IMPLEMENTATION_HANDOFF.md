## 不可丢失的产品决定

- MoonBit 实现 SAV 解析、字典/变量重组、传统压缩、类型/标签/缺失语义与导出/checker；不是 ReadStat 包装器。
- 小端 IEEE754 FL2，压缩 0/1；必要长字符串、两类缺失、变量/值标签；四种目标编码必须固定 profile 和变体边界。
- Node CLI 为首个完整交付平台；其他后端字节库按 PRD 明确支持范围。Node 能创建 TextDecoder 不等于 SAV 编码正确。
- 字符串没有数值型系统缺失；值标签不是缺失声明；日期保留原值及格式，不自动转换。
- 完整 bundle 始终有 `data.ndjson`、metadata、codebook、manifest，默认 CSV profile 另带标准 `data.csv`。NDJSON 带逐格原字节/数值位及 missing-kind；CSV 无反斜杠私有转义。check-bundle 核对两者一致性与状态，不能伪称来源认证。
- 本机 Node 实验显示 GBK/GB18030 非单射映射；Python/Node 的部分输出不同。它们不证明 SPSS 比较规则，必须通过资料与 PSPP/ReadStat 等独立工具验证 profile 和 string_matching_policy。
- 输出排他创建目录、INCOMPLETE/提交点、提交前后恢复和资源预算不能省略。
